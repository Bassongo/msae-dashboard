# 📊 MSAE Dashboard - Tableau de Bord Intelligent

Dashboard professionnel pour la **Mutuelle de Santé des Agents de l'État du Sénégal (MSAE)**.

![Dashboard](https://img.shields.io/badge/Status-Production%20Ready-success)
![Python](https://img.shields.io/badge/Python-3.9+-blue)
![Dash](https://img.shields.io/badge/Dash-2.14+-orange)

## 🎯 Fonctionnalités

### 📈 Indicateurs Clés (KPI)
- **Ratio Combiné** - Suivi de la rentabilité
- **Adhérents Actifs** - Nombre de membres
- **Prestataires Actifs** - Réseau de soins
- **Délai Moyen** - Temps de traitement
- **Cotisations & Remboursements** - Flux financiers
- **Coût Moyen par Dossier** - Analyse des coûts
- **Taux de Fraude** - Détection intelligente
- **Top Service** - Service le plus utilisé

### 📊 Visualisations Modernes
- **Graphique Ratio Combiné** - Évolution avec zones d'alerte
- **Graphiques Financiers** - Cotisations vs Remboursements
- **Donut Chart** - Distribution des services
- **Funnel Chart** - Workflow des réclamations
- **Heatmap** - Activité hebdomadaire

### 🔍 Détection de Fraude
- Machine Learning (Isolation Forest)
- Détection automatique des anomalies
- Tableau des dossiers suspects

### ⚙️ Filtres Dynamiques
- Plage de dates personnalisable
- Filtrage par type de service
- Mise à jour en temps réel

## 🚀 Installation Locale

### Prérequis
- Python 3.9+
- pip

### Installation

```bash
# Cloner le repository
git clone https://github.com/VOTRE_USERNAME/msae-dashboard.git
cd msae-dashboard

# Installer les dépendances
pip install -r requirements.txt

# Lancer l'application
python msae_dashboard.py
```

Ouvrir dans le navigateur: **http://localhost:8050**
